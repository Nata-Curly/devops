# install_dev_tools.sh — Автоматичне встановлення середовища розробки

## Опис
Цей Bash-скрипт автоматично встановлює основні інструменти для веброзробки на Ubuntu / Debian:

- **Docker**
- **Docker Compose**
- **Python 3.9+**
- **pip3**
- **Django**

Скрипт перевіряє, чи інструменти вже присутні в системі, щоб уникнути повторного встановлення.

---

## Використання

1. Клонувати репозиторій та перейти у гілку `lesson-3`:
```bash
    git checkout lesson-3
```
2. Зробити скрипт виконуваним:
```bash
    chmod u+x install_dev_tools.sh
```
3. Запустити скрипт:
```bash
    ./install_dev_tools.sh
```
